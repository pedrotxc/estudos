# Repositório de Estudos

Este repositório reúne diversos projetos desenvolvidos para fins de estudo e aprendizado contínuo.

Cada pasta representa um projeto independente, podendo ser referente a:
- Cursos
- Aulas
- Estudos de um tema específico
- Testes e experimentações técnicas

O objetivo é centralizar a evolução do conhecimento, praticar boas práticas de desenvolvimento e manter um histórico organizado dos estudos realizados ao longo do tempo.
